🚀 Local Quick Start Guide

Follow these steps to launch the entire PixelVerse virtual world locally in less than 2 minutes:

  1. Install Project Dependencies: 
    npm install
  2. Set Up Environment Configurations:

    Duplicate the environment template file and provide your connection strings:

    cp .env.example .env
  3. Initiate Database Migrations (Optional):

    If you have Neon PostgreSQL URL specified, push the schema. If database is not present, PixelVerse will automatically activate zero-config in-memory mode:

    npx prisma generate
  4. Run Frontend & Real-Time Socket Servers:

    Open two separate terminal windows to run both servers concurrently:

    # Terminal Pane 1: Boot Next.js Application Client
npm run dev

# Terminal Pane 2: Boot Real-time Express Socket.io Gateway
npm run server
  5. Open your web browser:

    Navigate to http://localhost:3000. Enter a Guest username and jump right in!

⚡ System Architecture & Realtime Workflow

PixelVerse operates on a split-mesh client-server synchronizer designed for heavy loads:

🌍 Coordinates Sync Workflow

  • User moves using WASD or arrow keys.
  • Phaser client registers physics velocity, updates position, and transmits vector updates to the socket server at 20Hz.
  • The Socket.io server receives position coordinates and broadcasts them to all other sockets inside the same map.
  • Other clients interpolate positions using Phaser tweens over 100ms for fluid visual updates.

💾 Database Strategy (Neon Postgres)

  • We utilize Prisma 7 configured for PostgreSQL.
  • Connections utilize the serverless PrismaNeon adapter over WebSockets, optimized for zero connection exhaustion in lambda functions.
  • Zero-Friction Fallback Layer: If Neon credentials are not configured, database triggers automatically reroute to high-speed memory arrays. No setup required to preview!
